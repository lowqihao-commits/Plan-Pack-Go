# Plan Pack Go frontend prototype

Mobile-first React and Vite prototype for the approved Plan Pack Go flow.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. The primary review viewport is `390 × 844`.

## Current implementation slice

Splash → Login / Sign Up → My Trips → Trip Name → Solo / Group → Group Invite (Group only) → Trip Dates → Solo or Shared Waiting List.

Later flows are intentionally not implemented in this slice.
